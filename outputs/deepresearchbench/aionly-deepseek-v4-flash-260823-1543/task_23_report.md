# 全国高校教师教学创新大赛（创新赛）与全国高校青年教师教学竞赛（青教赛）一等奖获奖课程综合研究报告

## 一、两类赛事总体概述

### 1.1 全国高校教师教学创新大赛（创新赛）

全国高校教师教学创新大赛由**教育部高等教育司指导、中国高等教育学会主办**，自2020年起每年举办一届，是纳入《教育部直属单位三评一竞赛保留项目清单》的唯一一项高校教师教学竞赛，被称为教师教学竞赛中的"奥林匹克"。大赛以"推动教学创新，培养一流人才"为主题，采用**校赛、省赛、全国赛三级赛制**，评审包含三部分：**课堂教学实录视频、教学创新成果报告、教学设计创新汇报**。第三届起设置新工科、新医科、新农科、新文科、基础课程、课程思政六大组别，每组按正高、副高、中级及以下三个职称分设小组；第四届起增设产教融合赛道；第五届进一步扩展至9个赛道（新增人工智能+、新教师）[1][2][8]。

### 1.2 全国高校青年教师教学竞赛（青教赛）

全国高校青年教师教学竞赛由**中华全国总工会、教育部联合主办**，中国教科文卫体工会和教育部教师工作司承办，自2012年起每两年举办一届，是覆盖面最广、学科门类最全、组织规模最大的全国性高水平教学类竞赛，已列入全国总工会"十四五"全国引领性劳动和技能竞赛。决赛设**文科、理科、工科、医科、思想政治课专项五个组别**，以**"上好一门课"**为核心理念，由**教学设计、课堂教学（20分钟无生授课）、教学反思**三部分组成。每组别设一等奖5名、二等奖10名，各组别第一名且符合条件的选手可申报"全国五一劳动奖章"[3][4]。

### 1.3 两赛关键差异

| 维度 | 创新赛 | 青教赛 |
|------|--------|--------|
| 主办单位 | 中国高等教育学会（教育部高教司指导） | 全国总工会、教育部 |
| 举办频率 | 每年一届 | 每两年一届 |
| 组别设置 | 按学科赛道＋职称分层（9赛道） | 5个学科组别（不按职称） |
| 核心材料 | 课堂实录视频＋创新成果报告＋现场汇报 | 16学时教学设计＋20分钟无生授课＋反思 |
| 年龄限制 | 无 | 40周岁以下（第八届） |
| 侧重点 | 课程整体教学创新改革 | 单堂课的教学基本功与设计能力 |

## 四、评审标准与评分要点

### 4.1 创新赛评审体系

**总体结构**：创新赛评审由课堂实录视频（网评）、教学创新成果报告（网评）、教学设计创新汇报（现场评审）三部分组成。分值权重经历演变：**首届（2020年）为50/15/35**（实录视频50%、成果报告15%、现场汇报35%）[33]；**第四届起调整为40/20/40**，并沿用至第五届[34]。

**第四届官方评分标准（主赛道，总分100分）**：

1. **课堂教学实录视频（40分）**：
   - 教学理念：体现"学生中心"、立德树人、学科特色，以"四新"建设为引领；
   - 教学内容：深度、广度、高阶性、创新性、挑战度、行业与社会关联；
   - 课程思政：价值塑造与知识能力培养有机融合；
   - 教学过程：学生中心的教学创新、目标明确、组织有序、方法创新、信息技术运用、形成性评价；
   - 教学成效：讲授有吸引力、学生参与度高、模式可迁移；
   - 视频质量：画面清晰流畅真实。

2. **教学创新成果报告（20分）**：
   - 问题导向明确（基于真实课堂问题、关注学生发展）；
   - 创新特色明显（将"四新"要求贯穿教学全过程）；
   - 课程思政特色；
   - 注重技术在教学中的应用；
   - 创新成果辐射影响（基于证据的分析、可推广的新方法/新模式）。

3. **教学设计创新汇报（40分）**：
   - 理念与目标、内容分析、学情分析、课程思政融合、过程与方法、考核与反馈、文档规范、设计创新八个维度。

**课程思政组**采用"课堂教学实录视频（40分）＋课程思政创新报告（20分）＋教学设计创新汇报（40分）"结构，其中创新报告侧重课程思政的问题导向、创新举措、创新成效与成果辐射[34]。

**视频技术要求（第四届）**：须为参赛课程中**2个完整的1学时课堂教学实录**，连续录制，机位不超过2个，不得使用摇臂、无人机等脱离实际课堂的录制方式；不得配音、不得画中画、不得出现身份信息；MP4格式，720P以上，单个文件不超过1200MB，命名"课程名称+教学内容"[34]。

**省级评审参考（安徽省第五届）**：网络评审60分（课堂实录视频40分＋创新成果报告20分）＋现场评审40分（12分钟教学设计创新汇报＋8分钟问答）；校级选拔亦参照此结构（如常州工学院校赛为网评60分＋现场40分，15分钟汇报＋10分钟问答）[35][37]。

**匿名要求**：除申报书外，所有材料及现场汇报不得出现教师姓名、学校、院系名称（产教融合赛道可体现行业企业信息）[33][36]。

### 4.2 青教赛评审体系

**总体结构**：青教赛坚持"上好一门课"理念，由**教学设计、课堂教学、教学反思**三部分组成，总分100分，分值结构为**20分、75分、5分**（全国通用参照，多份省级官方文件一致确认）[38][39][40]。

**评分细则（以第四届江苏省实施方案为例）**：

1. **教学设计（20分）**：提交参赛课程教学大纲、16学时教学设计方案及对应PPT（每学时对应20分钟课堂教学）。评价教学设计的完整性、科学性、创新性。

2. **课堂教学（75分）**：决赛现场随机抽取一个教学节段，进行20分钟"无生教学"模拟课堂讲授。分四个维度：
   - 教学内容（30分）：容量与深度、重点难点把握、理论联系实际、学科前沿与课程思政融入；
   - 教学组织（30分）：教学过程安排、方法运用、启发性与互动设计、时间分配；
   - 语言教态（10分）：普通话标准、表达清晰生动、教态自然大方；
   - 教学特色（5分）：教学理念、方法、技术应用的特色与创新。

3. **教学反思（5分）**：课堂教学结束后45分钟内，在不带任何资料的情况下完成不超过500字的书面反思，围绕教学理念、教学方法、教学过程展开。

**材料要求**：除封面外，参赛材料不得出现选手姓名和学校信息；教学节段与顺序比赛当日抽签确定；允许使用模型、挂图等教具[38]。

**省级差异提示**：部分省市在国赛框架下有所调整，例如江苏省第四届省赛另设"课程思政建设基础知识测试"3分（笔试），课堂教学习相应调整为72分；重庆市第八届市赛采用30/70结构；西藏大学校级赛为20/80结构。辅导备赛时务必以目标赛事的官方通知为准[41][42]。

### 4.3 两赛评审共性要点

- **双匿名评审**：两类国赛均严格匿名，材料中不得出现姓名与学校信息；
- **以学生为中心**：两赛评审均强调学生参与、学习成效与目标达成；
- **课程思政**：近几届两赛均将课程思政作为重要评审维度；
- **信息技术应用**：数字化教学工具、智慧教学手段的合理运用是加分关键；
- **可迁移可推广**：创新赛尤其看重教学模式的可推广性，青教赛看重教学基本功的示范性。

## 五、获奖案例资料获取渠道与整理建议

### 5.1 官方获奖名单与公告渠道

- **中国高等教育学会官网及培训中心网站**：历届创新赛获奖名单公告均以PDF附件发布，如第四届公告（2024年7月31日）[2]、第五届公告。访问路径：中国高等教育学会官网（www.cahe.edu.cn）或中国高等教育培训中心（chetc.cahe.edu.cn）"通知公告"栏目。
- **教育部官网**：青教赛各届决赛新闻稿（含各组一等奖第一名名单）发布于www.moe.gov.cn[3][4]。
- **全国总工会·中国教科文卫体工会官网**：通知公告栏目（jkwwt.acftu.org/jkwwttzgg）发布青教赛国赛通知等文件[32]。
- **创新赛报名系统**：https://nticct.cahe.edu.cn（大赛通知、材料提交、赛程信息均在此发布）[36]。
- **各省教育厅官网/教育工会**：发布省赛通知、获奖名单及推荐国赛名单公示，如安徽省教育厅（皖教秘高〔2025〕39号）[35]、上海市教委（沪教卫党〔2026〕6号公示）[49]、福建省教育厅[11]、黑龙江省教育厅（含拟获奖公示PDF）[20]。

### 5.2 课堂实录视频与示范课资源

- **国家高等教育智慧教育平台（重点渠道）**：首批115门全国高校教师教学创新大赛获奖课程完整课堂实录视频已于2026年1月上线。访问方式：https://higher.smartedu.cn/teacher ，点击"教师教研"模块。中国高等教育学会将分批次发布历届国赛获奖课程实录，打造"可观摩、可借鉴、可推广的教学创新资源库"；第六届大赛获奖课堂实录也将上传该平台[23][43]。这是目前最权威、最系统的获奖课堂实录公开渠道。
- **青教赛决赛视频**：第六届、第七届全国赛决赛的完整参赛视频在B站等平台可检索到（如"未来马良"频道收录的第六届五组决赛视频；第七届各组一等奖获奖视频亦有传播）[47][48]。第七届决赛期间通过央广网、全国总工会微信视频号、工人日报客户端等平台直播[26]。
- **高校官方喜报与专题报道**：各获奖高校官网新闻常附带课程简介、创新点总结与备赛经验，如武汉大学测绘学院[14]、北京邮电大学[15]、南京理工大学[19]、同济大学[21]、清华大学[25]、西北工业大学[28]等，是重要的二次学习材料。

### 5.3 教学设计文本与案例出版物

- **青教赛**：参赛教学设计、PPT按竞赛规则匿名提交，竞赛视频版权归组委会办公室，**全国级获奖选手的教学设计文本未见统一公开出版或上线**，属于未公开资料。
- **创新赛**：参赛材料（申报书除外）匿名且不公开；中国高等教育学会正在通过国家智慧教育平台分批发布获奖课程实录，但**配套教学设计文档（教案、创新报告全文）未见系统公开**。
- **案例图书**：高等教育出版社已作为第六届大赛支持单位参与[44]，但截至检索日期（2026年8月），尚未核实到已出版的《全国高校教师教学创新大赛获奖案例集》类正式书目，需后续关注高教社及学会出版物动态。

### 5.4 学术文献与二次分析资料

- **知网检索建议**：以"全国高校教师教学创新大赛""高校青年教师教学竞赛""教学创新 获奖案例"等为关键词检索。已有学者发表赛事研究论文，如赵富学《"全国高校教师教学创新大赛"体育课程思政教学创新审视》等[50]，可作为分析获奖课堂教学设计的学术参考。（注：具体论文条目需在知网按上述关键词进一步检索核实。）
- **省级大赛通知附件**：各地省赛通知附件常包含评分标准、材料要求、名额分配等操作性文件，对辅导备赛极具参考价值，如安徽省第五届省赛通知（含完整评分与时间线）[35]、江苏省第四届青教赛实施方案[38]。

### 5.5 系统化整理建议

1. **建立"获奖名单-课程-资料"三级台账**：以届次、赛道/组别、获奖教师、单位、课程名称为索引，逐条补充可获取的课堂实录链接、高校报道链接、创新点摘要；
2. **优先利用国家智慧教育平台**筛选与本校学科相近的获奖课程实录，组织教师观摩与研讨；
3. **关注省教育厅官网"公示"栏目**：省赛公示名单通常比国赛公告更早发布且包含组别信息，可作为国赛名单的补充与交叉验证；
4. **对接本校教师教学发展中心/教务处**：获取校内集训辅导材料与往届参赛教师经验分享；
5. **跟踪中国高等教育学会官方发布**：关注学会对获奖课程的后续发布计划（分批次上线实录）及出版物动态。

## 六、信息可获得性限制说明

1. **完整获奖名单**：创新赛各届完整一等奖名单仅以中国高等教育学会公告的PDF附件形式发布，公开网页摘要无法完整呈现；本报告所列一等奖获奖者仅为公开渠道可交叉核实的部分。青教赛官方通稿通常只公布各组一等奖第一名，**每组5名一等奖的完整25人名单未见统一官方文件公开发布**。
2. **获奖课程名称**：多数高校喜报未公布获奖课程名称，本报告仅能列出已核实课程（如《数字地形测量学》《机器人机械设计》《中国玉雕与玉文化》《中国古代城市规划史》《极端生物学》等）。
3. **教学设计文件**：两赛参赛教学设计、创新报告均为匿名评审材料，未公开；青教赛视频版权归组委会，往届决赛直播回放是否长期可点播无法核实。
4. **往届全部课堂实录**：创新赛并非全部实录公开，仅国家智慧教育平台分批发布精选获奖课程（首批115门，2026年1月上线）。
5. **评审内部材料**：专家评分原始表、评审意见属于内部材料，未公开；公开的仅为大赛通知附件的评分标准。
6. **个别信息矛盾**：百度百科关于第三届湖南人文科技学院马银花团队获新农科副教授组"二等奖/三等奖"的表述存在矛盾，无法完全核实；第五届"优秀组织奖"数量以中国高等教育学会公告及央视网、EOL报道的21项为准。
7. **时效性**：截至2026年8月23日，青教赛第八届国赛尚未开赛、获奖名单未产生；创新赛第六届（2026）获奖名单已公布但获奖课程详细报道尚在陆续发布中。

## 七、总结

创新赛与青教赛作为目前国内最具影响力的两项国家级高校教师教学竞赛，其一等奖获奖课程代表了当前高校课堂教学改革与青年教师教学能力的最高水平。创新赛近三届（第三、四、五届）分别产生一等奖72项、73项（主赛道，另产教融合赛道12项）、88项，覆盖新工科、新医科、新农科、新文科、基础课程、课程思政及产教融合、人工智能+、新教师等赛道；青教赛第六、七届分别产生5组别各5名一等奖，其中各组第一名及其参赛课程（如《中国古代城市规划史》《极端生物学》《中国近现代史纲要》等）已由教育部官方确认。评审标准方面，创新赛当前采用"课堂实录40分＋创新报告20分＋现场汇报40分"结构，青教赛采用"教学设计20分＋课堂教学75分＋教学反思5分"结构。资料获取上，**国家高等教育智慧教育平台（higher.smartedu.cn/teacher"教师教研"模块）是最权威的获奖课堂实录观摩渠道**，中国高等教育学会官网、教育部官网、全国总工会及各省教育厅官网是官方名单与赛事文件的一手来源；完整教学设计文本、专家评审意见等内部资料未公开，需通过高校官方报道、学术论文与省赛通知附件等间接材料加以补充。
