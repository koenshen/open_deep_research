# 中国国内地铁（城市轨道交通）碳滑板行业研究报告：市场规模、竞争格局与趋势分析

## 摘要

受电弓碳滑板是地铁列车与接触网直接接触的受流部件，属于典型的轨道交通核心耗材（MRO件），其需求由在役车辆保有量、运行里程和更换周期决定，而非新车交付量。本报告基于行业协会统计、第三方市场研究、上市公司/挂牌公司披露、招投标公告及学术论文等公开信息，对中国地铁（城市轨道交通）碳滑板的年度用量、市场规模、供应商格局及行业趋势进行系统梳理。

**核心结论：**
- 全球受电弓碳滑板市场2025年销售额约2.05亿~2.42亿美元（约15亿~17亿元人民币），产量约200万条，均价约160美元/条；中国市场（全部电气化铁路口径）年消耗量在50万条以上。
- 中国地铁（城轨）碳滑板年消耗量缺乏官方直接统计数据，本报告基于保有量、磨耗寿命、更换频次的**自下而上估算约为5万~10万条/年（全部城轨制式），对应金额约0.6亿~1.5亿元/年**；考虑异常磨耗等因素，上限可达15万条/年、约2亿元/年。其中**维保更换需求占绝对主体（约92%~98%），新建线路首装需求占比仅约2%~8%**。
- 竞争格局上，全球市场由Schunk（德国崇德）、Morgan Advanced Materials（英国摩根）、Mersen（法国美尔森）三大国际巨头主导（合计约55%份额）；国内厂商以苏州东南佳、北京万高众业为代表，正在加速国产替代，浸金属碳滑板国产化率预计从当前的约30%提升至2028年的60%以上。
- 行业已从高速建设期转向"存量运营+维保驱动"阶段，未来3-5年地铁碳滑板市场将保持稳定小幅增长（全球CAGR约0.3%~2.2%），技术迭代（浸金属碳、碳纤维复合、智能滑板）和国产替代是主要结构性机会。

## 一、年度用量与市场规模

### 1.1 总体市场口径：第三方研究机构数据

受电弓碳滑板市场目前没有官方统计口径，主要依赖第三方市场研究机构估算。不同机构因统计范围（全球/中国、全轨道交通/仅地铁）和方法差异，数据存在出入：

**（1）QYResearch（恒州博智）口径**
- 2025年全球轨道交通受电弓碳滑板市场销售额达**20.49亿元人民币**（约2.05亿美元），预计2032年达21.15亿元，2026-2032年CAGR为**0.3%**。
- 2025年全球产量约**200万条**，市场平均价格约**160美元/条**（约合人民币1,100~1,150元）。
- 中国市场方面，预计2032年受电弓用滑板市场销售收入可达**3.11亿美元**，2026-2032年CAGR约0.3%[2][3]。

**（2）共研产业研究院口径**
- 2025年全球受电弓滑板市场销售额约**2.42亿美元**，2026年预计2.44亿美元，2026-2032年CAGR约**2.2%**，2032年将达2.78亿美元。
- **中国铁路总里程超16万公里，其中约12万公里为电气化铁路，每年消耗受电弓滑板50万条以上**（注：此为全部铁路含高铁、普速、城轨的口径）。
- 结构判断：高铁（250km/h以上）更换频率为常规线路的3-5倍，是价值最高的细分；**城市轨道交通虽然单价较低，但提供了最大的销量基数**[1]。

**（3）Global Info Research（GIR/环洋市场咨询）口径**
- 2025年全球轨道交通受电弓碳滑板收入约**3.10亿美元**，预计2032年达3.20亿美元，CAGR为0.3%；产量约200万条，均价160美元/条。地铁/轻轨是增长最快的需求细分市场，需求由在役车辆的利用率和维护频率驱动[3]。

**（4）万高科技研究报告口径（2017年发布，预测2020年）**
- 预计到2020年中国受电弓碳滑板市场总需求约**18亿元**，其中**更换需求约17.5亿元**，**新装需求仅约3,000万元**；同报告另引用"年度市场规模约4亿元"（部分转引为40亿元，疑为误植）。
- 核心逻辑：碳滑板是耗材，高铁每约10万公里（约2个月）更换一次，每年需更换约6次；高铁受电弓碳滑板单价4,000-5,000元/条[4]。

### 1.2 地铁细分市场用量估算（自下而上）

**数据缺失说明：** 目前没有任何公开渠道（行业协会报告、上市公司年报、招投标公告、券商研报）直接披露"中国地铁碳滑板年度消耗总量"的精确官方数字。中国城市轨道交通协会的年度装备统计报告不公开碳滑板这类消耗件的分项数据；上市公司层面，万高众业曾挂牌新三板但未在公开渠道披露碳滑板销量明细，东南佳为非上市企业。因此，以下估算基于公开的车辆保有量、磨耗寿命实测数据和更换周期参数。

**估算基础参数：**

| 参数 | 数值 | 来源 |
|---|---|---|
| 全国城轨车辆保有量 | 超7万辆、12,314列（2024年底） | [7] |
| 地铁车辆占比 | 约75%（2024年新车采购中地铁占75.05%） | [7] |
| 每列车受电弓及碳滑板配置 | 每列6节编组通常配2个受电弓，每弓2条滑板，即每列在装4条 | [14][39] |
| 地铁碳滑板规格 | 长800-1,500mm、宽50-80mm、厚10-37mm，浸金属碳密度约2.25g/cm³，单条约4.0-4.5kg | [14][40] |
| 实测磨耗率 | 0.9-1.3mm/万公里（重庆轨道交通1号线，金属浸碳材料） | [14] |
| 可用磨耗厚度 | 初始37.51mm，磨耗极限24mm，可用13.5mm | [14] |
| 磨耗寿命 | 约10.4万-15万公里（按实测磨耗率）；东南佳产品按8万公里标准设计、实际寿命达9万公里以上 | [14][18] |
| 地铁列车年运行里程 | 约10万-15万公里/列 | [4] |
| 碳滑板单价 | 全球均价约160美元/条（约1,100-1,150元）；地铁级浸金属碳滑板约1,000-2,000元/条 | [2][3] |

**估算过程：**
- 全国城轨列车约12,314列（2024年底），其中地铁列车按75%计约**9,000列**；每列在装4条碳滑板。
- 按实测磨耗寿命10万-15万公里、年运行12万公里计算，每列每年正常更换约1-1.5次，即每列每年消耗**4-6条**；若按8万公里设计寿命并考虑偏磨、掉块、电弧烧蚀等异常损耗，更换频次可达1.5-2次/年，即**6-8条/列/年**。
- 全国城轨碳滑板年消耗量估算：**约5万-10万条**（其中地铁约4万-8万条），按单价1,000-2,000元/条计，对应金额约**0.6亿-1.5亿元/年**；若按更高更换频次和更宽价格区间，上限可达**15万条/年、约2亿元/年**。

**招投标数据的交叉验证：** 南昌轨道交通2025年度检修碳滑板采购项目（覆盖约100列规模线路）要求供应商近60个月内具有单项合同金额50万元及以上的城轨碳滑板供货业绩[11]；徐州地铁2025-2027年度采购入库项目（覆盖1、2、3号线及3号线二期）要求30万元以上业绩[13]。按每列车年消耗4-6条、单价约1,200元估算，一条中型线路（80-100列）年采购金额约40万-70万元，与上述业绩门槛基本吻合，验证了自下而上估算的合理性。

### 1.3 新建首装与维保更换需求结构

- **万高科技报告口径（全轨道交通含高铁）**：更换需求约17.5亿元，新装需求约3,000万元，**维保更换占比约98%、首装占比约2%**[4]。
- **地铁口径测算**：2024年全国城轨采购新车3,784辆、交付5,473辆[7]。按每辆车平均配置约0.67条（6节编组2弓×2条÷6辆），新装需求约2,500-3,700条/年，按1,200元/条计约**300万-440万元/年**，占地铁碳滑板年总需求（0.6亿-1.5亿元）的**约2%-8%**。
- QYResearch也明确指出，受电弓碳滑板作为MRO项目，"需求与短期车辆交付的相关性较低，而与在役车辆的利用率和维护频率更为密切相关"[2]。

### 1.4 数据来源与估算方法总结

本报告采用**"自上而下"（第三方研究机构市场规模）与"自下而上"（保有量×更换频次×单价）相结合**的方法。自上而下数据（全球市场、中国全部铁路口径）来自QYResearch、共研产业研究院、GIR等机构；自下而上数据基于中国城市轨道交通协会的车辆保有量统计、学术论文中的实测磨耗率、招投标公告中的采购规模交叉验证。由于缺乏官方直接统计，地铁细分市场的数据以估算区间呈现，建议读者结合不同口径综合判断。

### 2.3 市场份额格局

**（1）全球格局：国际巨头主导，中国企业份额上升**
- 全球第一梯队Schunk、Morgan、Mersen三家合计约占全球**55%**市场份额（2025年，共研产业研究院口径）[1]。
- 第二梯队为Wabtec/PanTrac（美国）、TOYO TANSO（日本）等轨交装备龙头[1]。
- 中国企业（东南佳、溢洋墨根、辽宁红德、万高众业、锦美碳材等）目前全球份额约**12%**，预计2030年将超过20%[1]。

**（2）中国市场：国产化率快速提升**
- 中国浸金属碳滑板国产化率目前约**30%**，预计2028年达到**60%以上**；纯碳滑板曾全部依赖进口，国产浸金属碳滑板自2018年起开始高铁装车验证[1][23]。
- 高铁细分市场：万高众业（作为Hoffmann总代理）市场占有率超过50%[4]。
- **地铁细分市场：无任何公开数据披露各厂商具体份额**。从招投标实例看，南昌地铁2025年度采购第一中标候选人为苏州东南佳、第二为万高众业、第三为上海鼎襄，说明国产厂商在地铁市场已占据主导地位[12]。国际品牌（Schunk、Mersen、E-Carbon等）通过直接投标或代理渠道参与竞争，E-Carbon在上海、广州、深圳等地铁线路有历史装车记录[22]。

**（3）竞争特点**
- 进入壁垒高：EU TSI和中国CRCC认证周期长达2-3年；CRCC认证是进入中国铁路市场的必要条件；需通过国家铁路局检验检测细则（如GTJ0004—2024《受电弓碳滑板检验检测细则》）及主机厂装车运行考核[1][41]。
- VPI（真空压力浸渗）核心工艺专利主要掌握在Schunk、Mersen手中，中国企业在材料配方专利和极端工况验证数据上仍落后[1]。
- 原材料成本占总成本50%-60%（石墨/碳、铜合金、铅锡合金），铜价8,000-10,000美元/吨（2024-2025年）、高等级石墨价格上涨15%-20%，对中小企业形成成本压力[1]。

## 三、行业趋势分析

### 3.1 地铁线路建设速度与碳滑板需求的关联趋势

**建设端已过峰值，进入存量运营主导阶段：**
- 城轨建设投资2020年达到峰值**6,286亿元**，2025年降至**4,114.16亿元**（同比下降13.38%）[8]。
- 年新增运营里程峰值出现在2021年（**1,237.1公里**），2025年新增仅**764.7公里**[5][9]。
- 截至2025年底，全国54个城市开通城轨线路343条，运营里程**11,710.3公里**（交通运输部口径）；中国城市轨道交通协会口径2024年底为58城361线12,160.77公里（口径差异源于统计范围不同）[5][6][7]。
- 中车城轨车辆订单从2022年约7,000辆降至2024年约2,000辆[9]。

**维保端进入密集周期：**
- 按照《城市轨道交通设施设备运行维护管理办法》，城轨车辆架修间隔不超过**5年或80万车公里**，大修间隔不超过**10年或160万车公里**，整体使用寿命一般不超过30年或480万车公里[28]。
- 2024年底城轨车辆保有量超7万辆、12,314列，2010-2021年新增车辆正集中进入架修/大修周期[7][26]。
- 据行业预测，**2026-2030年全国将有45个城市约40,729辆城轨车辆进行架修，38个城市约36,923辆进行大修**[12]；城轨维修市场2023年约680亿元，预计2025年超750亿元[26]。

**结论：** 新建线路对碳滑板的需求贡献持续萎缩，而存量车辆保有量（超7万辆）带来的维保更换需求是碳滑板市场的绝对主体，且随保有量增长和车辆老化稳步上升。碳滑板需求与"建设速度"的关联正在减弱，与"运营强度+维保周期"的关联增强[2][9]。

### 3.2 碳滑板技术迭代

**材料演进路径：** 金属滑板 → 纯碳滑板 → 粉末冶金滑板 → **浸金属碳滑板（当前主流）** → 碳纤维复合材料/智能滑板（前沿）[16][32][33]。

| 材料类型 | 特点 | 应用现状 |
|---|---|---|
| 纯碳滑板 | 自润滑、成本低，但载流能力有限、机械强度低、易断裂 | 份额下降，仍用于200km/h以下线路 |
| 浸金属碳滑板（VPI技术） | 载流能力为纯碳的3-5倍，机械强度提升40%-60%；兼具碳的自润滑与金属的导电/强度 | **高铁（250-350km/h）主流选择，2025年全球渗透率超65%，高铁采用率超80%**；地铁领域亦为主流 |
| 金属基复合材料滑板 | 导电性和强度最高，用于重载、高海拔等极端工况 | 成本高，尚未大规模商业化 |
| 碳纤维复合材料（C/C） | 弯曲强度和冲击强度为现有碳滑板的2倍以上，重量更轻 | 前沿方向；吉林聚能已规划年产2万件高铁受电弓用碳纤维滑板项目（总投资1.33亿元）[35] |
| 智能滑板（嵌入式磨损传感器） | 从定期维护转向状态修（CBM） | 进入试验阶段，Wabtec引领[1] |

**关键趋势：** 不断提高的电流水平、更严格的风险管理推动市场向浸金属化和金属化解决方案发展，并结合端部结构设计、电弧保护、防冰/加热功能等特性[2]。重庆轨道交通1号线实测数据（磨耗率0.9-1.3mm/万公里、线性磨耗趋势R²>0.87）表明，基于数字孪生和AI的磨损预测正在为"按需更换"提供技术基础[14]。成都地铁基于MI-LSSVR模型的磨耗预测拟合精度达97.3%[17]。北京地铁通过在19座重点车站安装智能湿度调控系统（控制站台相对湿度30%-40%），使碳滑板年度消耗量降低90%以上[31]。

### 3.3 国产替代趋势

国产替代是当前最确定的行业主线，已从"能用"走向"好用"：

- **认证突破：** 万高众业2013-2014年行业首家通过CRCC认证；东南佳拥有完全自主知识产权和全覆盖产品认证；大同新成获得CRCC认证和ISO 22163国际质量体系认证[4][18][23]。
- **高铁验证里程碑：** 2018年大同新成浸金属碳滑板在高铁装车运行18万公里（预计30万公里），超过国外顶级企业同类产品最高15.6万公里的纪录[23]；东南佳碳滑板已广泛用于"和谐号""复兴号"动车组[18]。
- **地铁市场：** 东南佳服务上海、广州、深圳、郑州、武汉等20多个城市地铁系统；南昌地铁2025年度采购第一中标候选人为国产厂商东南佳[12][18]。
- **量化目标：** 共研产业研究院预计中国浸金属碳滑板国产化率从当前约30%提升至2028年**60%以上**；中国厂商全球份额从约12%提升至2030年**20%以上**[1]。
- **国家战略支撑：** 《中国城市轨道交通国创城轨发展规划》提出核心技术自给率2030年达到**95%以上**、2035年达到**100%**的目标，并部署"卡脖子"技术突破、装备自主化强链等行动[29]。

### 3.4 行业政策影响

- **审批收紧：** 近年来中央不断提高城轨审批门槛，"城市轨道交通疯狂建设的年代已一去不复返"，城轨领域进入"优化运营、做好存量"阶段[9]。
- **智慧城轨与绿色城轨：** 《中国城市轨道交通智慧城轨发展纲要（修订版V2.0 2026-2035年）》于2026年4月发布，推动智能运维、预测性维护和绿色低碳转型，直接影响碳滑板等耗材的更换策略和需求节奏[6][8]。
- **标准化与认证：** 国家铁路局2024年12月发布GTJ0004—2024《铁路专用产品检验检测细则 受电弓碳滑板》，构成官方检验检测依据，提高行业准入门槛[41]。
- **维保政策：** 架修/大修周期（5年/80万车公里、10年/160万车公里）直接决定碳滑板等部件的更换节奏；部分城市试点延长检修周期（如成都地铁18号线大修延长至80万公里/6年），中长期可能降低单位里程更换频次，但短期（2023-2030年）集中进入维修周期的存量车辆反而推高需求[27][28]。
- **贸易与供应链政策：** 美国"Buy America"条款、欧盟关键原材料供应链自主战略对国内厂商出海构成壁垒；国内"一带一路"城轨项目（18个国家、32条建设线路）为碳滑板出口提供增量空间[1][29]。

### 3.5 未来3-5年市场预测（2026-2030）

**总体判断：稳定小幅增长，结构分化明显。**

1. **市场规模：** 全球受电弓碳滑板市场预计以0.3%-2.2%的CAGR缓慢增长（QYResearch与共研产业研究院口径差异），2030年前后全球市场约2.8亿-3.2亿美元；中国市场增速略高于全球，受城轨保有量增长和国产替代驱动。中国地铁碳滑板细分市场预计从当前的约**0.6亿-1.5亿元/年**增长至2030年的约**1亿-2亿元/年**（以维保更换需求为主）。
2. **需求结构：** 新建首装需求占比进一步下降（预计降至2%以下），维保更换需求占比持续提升。2026-2030年城轨架修40,729辆、大修36,923辆的集中释放，将推动碳滑板更换需求在2027-2029年达到阶段性高峰[12]。
3. **技术方向：** 浸金属碳滑板渗透率继续提升（年增4%-5%，2030年全球浸金属碳市场超2亿美元）；碳纤维复合滑板有望在地铁/市域快轨领域率先商业化；智能滑板（磨损传感器）从试验走向小批量应用，推动"状态修"替代"定期修"[1][35]。
4. **竞争格局：** 国产化率从约30%提升至2028年60%以上；国际巨头在高端高铁市场仍具优势，但在地铁市场国产厂商已占据主导；行业集中度有望提升，具备CRCC认证、规模产能和研发能力的企业（东南佳、万高众业等）将扩大份额，缺乏认证和成本优势的小企业面临出清[1]。
5. **风险因素：** 铜价和石墨价格波动（原材料占成本50%-60%）、城轨投资继续下滑、地方财政压力导致的维保预算收紧、部分城市试点延长检修周期等，可能使实际需求低于乐观预测[1][9][27]。

## 四、数据缺失与不确定性说明

本报告涉及的数据存在以下明确缺口，使用时需注意：

1. **地铁碳滑板年度消耗量无官方统计。** 中国城市轨道交通协会年度装备统计报告不公开碳滑板等消耗件数据；第三方研究机构（QYResearch、贝哲斯、共研）均未公开中国地铁单独细分市场的具体数值。本报告的地铁细分用量（5万-10万条/年、0.6亿-1.5亿元/年）为基于公开参数的估算区间，而非精确统计值。
2. **地铁碳滑板分厂商市场份额无公开数据。** 全球份额（前三强55%）、高铁份额（万高50%+）有研究机构或企业披露支撑，但地铁市场各厂商份额仅能从招投标结果（如南昌地铁中标候选人排序）做定性推断。
3. **价格数据分散。** 全球均价（160美元/条）与高铁单价（4,000-5,000元/条）有明确来源，但地铁级碳滑板的实际成交价因采购批量、线路条件、材料类型差异较大，本报告采用1,000-2,000元/条的估算区间。
4. **口径差异。** 交通运输部与中国城市轨道交通协会的运营里程/城市数统计口径不同（2025年底分别为11,710.3公里/54城与2024年底12,160.77公里/58城），引用时需注明来源。

## 五、结论

中国地铁碳滑板市场是一个典型的**"小产品、大耗材、强壁垒"**的利基市场：年消耗量约5万-10万条、金额约0.6亿-1.5亿元，规模不大但具有强刚性和抗周期性。市场已从建设驱动切换为**存量维保驱动**，更换需求占92%-98%。竞争格局上，国际巨头（Schunk、Morgan、Mersen）主导全球，但国产厂商（东南佳、万高众业等）正在地铁市场取得主导地位，并沿高铁市场向上突破，浸金属碳国产化率有望在2028年超过60%。未来3-5年，市场将保持稳定小幅增长，技术迭代（浸金属碳深化、碳纤维复合、智能滑板）、国产替代和维保周期释放是三大结构性机会。
