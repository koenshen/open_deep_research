# 中国市政污水收集处理系统改革方案：从“核拨制”到“按效付费”的全生命周期管理转型

## 一、现状诊断：核拨制的根本性缺陷与逆向激励

### 1.1 核拨制的运行逻辑

核拨制（又称“以拨代支”或“计划拨付制”）是中国绝大多数城市污水处理系统长期采用的财政资金分配方式。其核心特征是：地方财政局根据历史支出水平、谈判确定的预算额度或设计处理能力，向水务局或排水管理单位拨付资金，而非基于实际运行绩效或环境产出。这是一种典型的“投入导向型”预算模式。

### 1.2 核拨制造成的六大系统性低效问题

**1.2.1 “高处理率”与“低收集率”的结构性矛盾**

截至2024年，全国城市污水处理率达到98.93%，但2027年目标要求城市生活污水集中收集率仅为73%以上[1]。这意味着，大量污水从未被管网收集，或受到地下水渗入、雨水混入的严重稀释。核拨制下，“处理率”指标奖励的是处理厂的运行，无论其是否真正收集到了目标污染物，导致资金分配与实际环境效益严重脱节。

**1.2.2 “处理越多清水、财政补贴越多”的逆向激励**

2026年的一项针对厂网分离体制的分析明确指出，传统核拨制下存在一个根本性的逆向激励：按量付费模式使得“处理越多清水、财政补贴越多”[1]。当处理厂按处理水量获得补贴时，接纳地下水渗入、雨水混入的稀释进水反而更“划算”——因为稀释水处理成本更低，但产生的计费水量相同。这导致：

- 进水浓度低（因地下水稀释）的处理厂反而获得更高收益
- 进水浓度高、需要更多能源和药剂处理的厂得不到任何补偿
- 完全没有经济动力去修复破损管网、减少外来水渗入

**1.2.3 收费缺口与财政失衡**

据E20研究院院长傅涛分析，全国污水处理费平均应收账款周期为一年，资金缺口约2000亿元。2025年上半年，这一缺口仍在扩大。许多水务企业仅能收到“三保”资金（保电费、保药剂、保人工），其他成本长期拖欠[2]。评论指出：“让水务企业长期垫付资金不仅违背市场规律，还将直接冲击公共服务供给的可持续性。”

**1.2.4 收费水平低于实际成本**

2024年发表在《Water》期刊上的一篇综述文章发现，中国现行污水处理费仅能覆盖处理厂的运行成本，无法覆盖整个城市污水处理系统的全运行成本。样本厂平均运行成本为1.38元/吨，各区域平均缺口约0.31-0.45元/吨[3]。“缺乏全面、全成本、全生命周期的定价机制”是行业诸多问题的根源。

**1.2.5 污泥处理投入严重不足**

“十二五”期间，污泥处理投资仅占污水处理总投资的8%，远低于发达国家水平。“重水轻泥”问题的直接诱因就是资金分配不基于综合环境绩效。

**1.2.6 处理厂运行效率低下**

世界银行对中国北方城市的评估显示，污水处理厂平均仅达到设计水力容量的58%，存在大量闲置资产和基础设施未充分利用[4]。另一项基于动态DEA分析的研究发现，中国各省污水处理整体效率普遍偏低，非长江流域得分为0.504，长江流域得分为0.398，费用效率均低于0.4[5]。

**1.2.7 年底突击花钱现象**

核拨制下，预算按年度分配，未用完的资金通常收回国库。这导致一个普遍现象：各单位年底突击花完剩余预算，往往用于非优先事项或低效采购，仅为了避免第二年预算被削减——这是投入导向型预算的经典问题。

### 1.3 体制性障碍：事权在企、财权在政

改革面临的核心体制障碍是运营责任（事权）与财政权力（财权）的分离。具体而言，国企和水务公司负责运营（事权在企），而政府财政局控制资金（财权在政）。这导致：

- 企业必须垫付资金运行，等待报销
- 财政局没有直接运营责任
- 预算周期与运营需求不匹配
- 缺乏整合的成本-收益优化机制

更根本的问题是厂网分离——污水处理厂和管网由不同主体运营，资金来源不同。厂方无法控制进入厂区的污水，管网方对处理结果没有利益关联，整个系统缺乏统一的绩效问责制。

## 二、改革总体框架：建立“四位一体”的新型排水系统治理模式

### 2.1 改革核心原则

1. **全生命周期成本覆盖**：从“只覆盖处理厂运行成本”转向“覆盖管网建设、运营、维护、改造、应急、污泥处置、雨水排涝协同等全链条成本”
2. **按效付费取代按量付费**：从“按处理水量付费”转向“按污染物收集效能、减排量、出水水质、污泥无害化等综合绩效付费”
3. **厂网一体化运营**：打破厂网分离，实现统一运营主体、统一调度、统一标准
4. **雨水-污水协同管理**：将排水系统与排洪排涝系统整合，实现“蓝-绿-灰”基础设施协同
5. **市场化定价与财政补贴相结合**：推进“费改价”，实现污水处理费向经营性水价转型，保留对弱势群体的精准补贴

### 2.2 改革总体架构

本方案的核心是“四位一体”改革框架：

```
┌─────────────────────────────────────────────────────────────┐
│                    四位一体改革框架                            │
├─────────────────────────────────────────────────────────────┤
│  1. 体制整合：建立统一排水管理主体，实现厂站网一体化运营          │
│  2. 付费改革：建立以污染物收集效能为核心的按效付费体系           │
│  3. 全生命周期成本管理：从建设到退役的全链条成本核算与优化        │
│  4. 雨水协同：排水系统与海绵城市、排洪排涝系统的深度整合          │
└─────────────────────────────────────────────────────────────┘
```

## 三、体制整合：建立统一排水管理主体

### 3.1 厂站网一体化运营模式

这是当前中国排水系统改革的核心方向。2024年3月，住建部等五部门联合出台政策，首次将“厂网一体化运维机制”纳入国家政策框架，创新性地建立了“以污染物收集效能为核心的绩效考核与按效付费体系”[6]。

**核心要求**：
- 将污水处理厂、提升泵站、管网系统纳入统一运营主体
- 统一运营调度、技术标准、服务质量、会计核算
- 打破多头管理、权责不清的局面

### 3.2 案例：上海市2025年排水管理体制改革方案

2025年3月，上海市政府发布《上海市排水管理体制改革方案》，这是中国城市排水体制改革中最具雄心的一项举措[7]。方案核心内容：

**改革范围**：到2026年底，黄浦、静安、徐汇、长宁、普陀、虹口、杨浦、宝山8个中心城区及浦东新区北部、嘉定区部分区域的雨水和污水公共排水设施，将全部移交上海城投集团，实现石洞口、竹园、白龙港三大都市排水区域的“厂站网一体化运维管理”。

**“五个不变”原则**：
- 规划建设责任不变
- 设施资产权属不变
- 政府监管职责不变
- 属地防汛责任不变
- 日常运行经费渠道不变

**“五个统一”原则**：
- 统一运维管理
- 统一技术标准
- 统一运行调度
- 统一服务质量
- 统一会计核算

**关键绩效目标**：
- 管道检测合格率≥95%（淤积深度≤管径10%）
- 污水处理厂进水BOD5年均浓度>100mg/L
- 污水处理厂无溢流（极端天气除外）
- 泵站排放符合生态环境要求
- 管网低水位运行，减少外来水渗入
- 中心城区道路标准降雨下无积水
- 应急响应30分钟内（跨区60分钟）

**实施时间表**：
- 2025-2026年：过渡期
- 2025年6月：各区实施方案完成
- 2025年10月：开始运营移交
- 2025年12月：完成移交
- 2026年底：全面实现厂站网一体化运营

**绩效管理创新**：
- 统一日常运行经费标准
- 建立绩效考核办法，设置技术创新激励
- 2026年起：市-区联合对城投集团进行绩效考核
- 考核结果与：运行经费拨付 + 国资委对国企领导的奖惩挂钩
- 2027年起：开展成本预算绩效分析，研究综合单价结算机制

### 3.3 案例：武汉市“厂网一体”改革成效

武汉水务局2026年3月报告，该市2025年启动的“厂网一体”改革已取得显著成效[8]：

**关键成果**：
- 2025年全市进水BOD平均浓度达到国家考核目标，比“十四五”初期提高30.15%
- 城市生活污水集中收集率升至83.65%，比“十四五”初期提高25.18%
- 试点项目：黄陂后湖（新城区）BOD浓度同比提高37.3%；黄家湖（中心城区）BOD浓度同比提高16.1%
- 排查并修复5400余处管网缺陷（5490/5610处已整改）
- 黄孝河、机场河等主要河流水质保持Ⅳ类

**三种整合路径**：
1. **调度整合**——全市25个污水系统实现统一调度
2. **运营整合**——6个系统实现统一运营
3. **建设管理整合**——管网整治与绿色产业发展同步推进

### 3.4 国际经验：新加坡PUB模式

新加坡提供了最有力的体制整合范例。2001年，新加坡通过《公共事业法》将整个水系统（从水源到污水处理、再生水利用）统一交由公共事业局（PUB）管理，实现了“闭环”管理[9]。这种“深度制度化”的治理变革使新加坡能够制定和实施更全面的战略，实现了更好的水安全成果。

**关键经验**：
- 统一机构负责所有涉水事务，打破部门壁垒
- 将水管理纳入城市发展总体规划
- 强大的机构协调能力
- 适应性管理（随着技术进步不断调整策略）
- 供需双侧管理

新加坡的“四大国家水喉”战略包括：本地集水（已扩大至17个水库，覆盖67%国土面积）、从柔佛输入水（至2061年）、新生水NEWater（满足30-40%需求，计划2060年达55%）、海水淡化（满足25%需求，计划2060年达30%）。PUB获得斯德哥尔摩水工业奖，以表彰其整体性方法[10]。

## 四、付费改革：从“按量付费”到“按效付费”

### 4.1 按效付费的核心逻辑

按效付费（Pay-for-Performance）的核心是：将资金拨付与实际环境绩效直接挂钩，而非与处理水量或预算计划挂钩。2023年12月，国家发改委、住建部、生态环境部联合发布《关于推进污水处理减污降碳协同增效的实施意见》，明确要求建立“与进水污染物浓度、污染物削减量、出水水质、污泥无害化等挂钩的按效付费机制”[11]。

### 4.2 按效付费的关键指标体系

基于国际经验和国内试点实践，建议建立以下核心绩效指标体系：

| 维度 | 核心指标 | 考核权重 |
|------|---------|---------|
| 污染物收集效能 | 进水BOD₅/CODcr浓度、集中收集率 | ≥30% |
| 处理效能 | 出水达标率、污染物削减量、能耗效率 | ≥25% |
| 管网运行质量 | 管道检测合格率、外来水渗入率、低水位运行率 | ≥20% |
| 应急响应能力 | 响应时间、事故处理率、防汛达标率 | ≥10% |
| 资源化利用 | 再生水利用率、污泥无害化处置率、能源自给率 | ≥10% |
| 用户满意度 | 公众满意度调查、投诉处理率 | ≥5% |

### 4.3 案例：长沙市的“按效付费”模式

长沙被公认为中国“厂网一体化按效付费”模式的先行者[12]。其核心模式特点：

- **“委托运营+绩效合同管理”**模式
- 30年委托运营协议
- 在城市区域试点“管网使用者付费”
- 处理厂和管网由同一主体管理，付款与实际污染物削减量挂钩，而非处理水量

2025年，长沙被选为全国12个供排水综合管理试点城市之一[13]。

### 4.4 案例：湖南省试点成效

截至2024年，湖南省城市污水收集率达到68.64%，比2023年提高1.52个百分点。新机制下，“处理厂和管网由一家管，付费与污染物削减量挂钩而非水量”。湘潭市实现黑臭水体100%消除，收集率从2020年的45.75%提升至76.6%。截至2024年9月，全省16家试点厂已采用该模式[14]。

### 4.5 国际经验：荷兰的绩效基准体系

荷兰的水务局（waterschappen）模式是“利益-付费-发言权”原则的典范。21个区域性水务局拥有防洪、水量和水质管理、污水处理等专属职能，通过自己的税收（水系统税和污染税）每年筹集约27亿欧元[15]。

荷兰建立了全国性的污水处理绩效基准体系，通过“行政水协议”（Bestuursakkoord Water），到2019年实现了6.68亿欧元的效率提升，超过原定4.5亿欧元的目标[16]。这一成功的关键在于：

- 共享所有权：水务局、企业、政府共同参与基准设计
- 标准化绩效指标：覆盖技术、财务、环境、社会维度
- 公开透明的绩效报告：阳光监管机制
- 绩效与费率挂钩：高效运营者获得更低成本资金

### 4.6 国际经验：澳大利亚IPART定价模式

澳大利亚新南威尔士州的独立定价与监管仲裁庭（IPART）为水务行业设定了独立于政府的定价机制。IPART采用“价格上限”模式，通过基准分析设定效率因子（X-factor），迫使企业持续提高效率[17]。

悉尼水务公司是澳大利亚最大的水务公司，服务超过400万人。改革成果：员工从1980年的14,000人减少至2010年的2,987人；超过80%的支出通过外部采购实现；成本效率显著提升[18]。

## 五、全生命周期成本管理（TOTEX/CAPEX/OPEX模型）

### 5.1 全生命周期成本核算框架

传统核拨制只关注处理厂运营成本，而全生命周期成本（TOTEX）管理要求覆盖：

- **资本支出（CAPEX）**：管网建设、处理厂建设、设备采购、信息化系统
- **运营支出（OPEX）**：能源、药剂、人工、维护、污泥处置
- **维护与更新（Maintenance & Renewal）**：管网修复、设备更新、技术改造
- **应急与抢险（Emergency）**：排涝、抢修、灾害应对
- **退役与处置（Decommissioning）**：设施退役、环境修复

对于污水泵送系统，采购价格仅占全生命周期成本的不到10%。详细成本构成：能源34%、维护26%、初始投资10%、运营8%、停机4%、环境6%、安装调试8%、退役4%[19]。研究表明，泵采购节省5-10%的成本，往往被最初几年运营中20-40%更高的能源和服务成本所抵消。

### 5.2 电费作为运营成本的关键组成部分

电力成本通常占全球水和污水处理厂运营成本的5-30%。在发展中国家，这一比例更高，可达40%以上[20]。世界银行/ESMAP报告指出，每项措施可实现10-30%的节能，投资回收期1-5年，全球节能潜力估计为34-168 TWh/年。

### 5.3 案例：深圳环水集团的数字化降本

深圳环境水务集团实施的“深水云脑”数字化系统，实现了14座污水处理厂的数字化运营，成果包括：电耗降低22%、人工成本降低50%、产销差从7.9%降至4.6%[21]。

### 5.4 国际经验：德国的生命周期成本法

德国采购法（VgV 2016、VOL/A）允许并在某些情况下强制要求在采购中考虑生命周期成本，特别是对于耗能产品。生命周期成本通常显示，尽管环保产品初始成本较高，但从全生命周期看更具经济性[22]。

奥地利建立了污水处理服务基准体系，历时6年（1999-2005）开发，应用于76家处理厂（2000-100万人口当量），约占全国处理能力的30%。关键发现：

- 总年度成本强烈依赖于规模：大型厂（>15万人口当量）约10欧元/人口当量/年，小型厂（<5000人口当量）超过70欧元/人口当量/年
- 运营成本与处理效率之间没有相关性——基准厂往往以最低成本实现最高效率
- 低设施利用率显著增加资本和运营成本
- 处理效率要求对总成本的影响相对较小（例如，从BOD去除升级到完全脱氮除磷仅增加约7%的成本）
- 员工素质和管理能力是决定性因素

### 5.5 国际经验：新加坡DTSS的百年设计

新加坡深隧道排污系统（DTSS）是长周期基础设施规划的典范。总投资约100亿新元，设计寿命100年。第一阶段（2008年完成）耗资34亿新元，包括48公里深隧道、连接管网、樟宜再生水厂和排放管道。第二阶段（2017-2025年，估计65亿新元）增加40公里隧道、大士再生水厂（日处理能力80万立方米）和连接管网[23]。

DTSS采用重力自流输送污水，消除了泵站，减少了土地占用（从300公顷减至190公顷，最终减至150公顷），并降低了污染风险。该工程获得国际水协会“项目创新奖”等多个奖项[24]。

关键经验：通过第二阶段融资使用SINGA债券（国家级绿色债券），体现了“跨代际收益共享”的融资理念——项目惠及多代人，因此通过长期债务融资是合理的[25]。

## 六、雨水-污水协同：构建“蓝-绿-灰”一体化排水系统

### 6.1 协同管理的必要性

中国城市排水系统面临的核心挑战之一是如何处理雨水与污水的交叉问题。在厂网分离和核拨制下，管网渗漏、雨污混接、地下水渗入导致进厂污水浓度极低，既浪费了处理能力，又增加了运营成本。同时，暴雨期间合流制溢流（CSO）污染严重，影响水环境质量。

### 6.2 海绵城市与排水系统的整合

中国海绵城市计划（SCP）是整合雨水管理、防洪排涝与污水处理的全国性政策。30个国家级试点城市于2019年通过住建部、财政部、水利部的联合验收[26]。

**关键挑战**：尽管海绵城市提供了有前景的框架，但其成功取决于“充足的资金、专业知识和公众参与”[27]。许多海绵城市项目未产生明确、固定的资产或明显的收入流，其提供的许多效益不易货币化[28]。

**成本效益分析**：海绵城市采用的低影响开发（LID）措施，在成本效益上优于传统方法。贵州贵安新区的研究发现，综合措施（生物滞留+透水路面+绿色屋顶）是最具成本效益的方案[29]。

### 6.3 国际经验：哥本哈根的云雨管理计划

丹麦哥本哈根的云雨管理计划（CMP）是整合雨水-污水-防洪的全球典范。2011年，一场两小时降雨150毫米的暴雨导致超过8亿欧元的保险索赔。CMP应运而生，旨在通过补充现有下水道系统，保护城市免受百年一遇降雨事件的影响。计划总投资约19亿欧元，包含300个项目，历时20年完成[30]。

**财务模式创新**：CMP的50%资金来自水费（通过水务公司HOFOR），10.5%来自市政税收，31.5%来自私人业主。这一模式的关键推动力是国家层面的法律修改——允许水务公司用水费共同资助多功能的蓝色-绿色基础设施，但需满足严格条件：蓝绿替代方案必须证明比灰色方案更具成本效益，资金仅用于与水相关的目的，水务公司不能主动发起项目[31]。

**成本效益分析**：采用蓝绿方案与社会“不作为”方案相比，100年内的社会经济盈余为50亿丹麦克朗；而传统下水道方案将导致社会损失40亿丹麦克朗。单一公园可在暴雨期间储存4万立方米的水[32]。与灰色方案相比，蓝绿方案节省了约2亿美元的投资成本。

### 6.4 国际经验：费城的绿色城市、清洁水域计划

费城的“绿色城市、清洁水域”计划是整合雨水管理和污水处理的成功案例。该计划25年投资24亿美元，相比之下，灰色方案（深隧）需要96亿美元——绿色方案节省了75%的成本[33]。绿色方案提供的净现值收益为28.5亿美元，而灰色方案仅为1.22亿美元[34]。

截至最新数据，该计划已超额完成前10年的污染减排目标，安装了超过2,800个绿色设施，覆盖近800个场地，防止超过27亿加仑的污染水进入河流[35]。项目创造了430个就业岗位，预计25年内产生31亿美元的经济影响，财产价值提升约10.3%，每年增加1800万美元的财产税收入。

### 6.5 雨水再利用的经济性

2026年发表在《npj Clean Water》上的文章发现，雨水衍生饮用水（0.20美元/立方米典型成本）在成本上介于地下水（0.05美元/立方米）和微咸水（0.40美元/立方米）之间，远低于海水淡化（1.10美元/立方米）。水平均成本为0.06-0.20美元/立方米，温室气体排放为0.14-0.35千克CO₂当量/立方米，能耗为0.3-0.8千瓦时/立方米[36]。

## 七、污水处理费改革：从“收费”到“价格”

### 7.1 “费改价”的核心逻辑

E20研究院傅涛提出的“费改价”改革方向，核心是：

- 将管网运营维护成本纳入污水处理费
- 最终将所有成本整合为综合经营性水价
- 建立与成本指数挂钩的动态调价机制
- 降低直接财政补贴比例
- 实施“受益者付费”，对弱势群体实行精准补贴
- 降低财政直接支付比例，同时保持可持续性

### 7.2 国际经验：荷兰的“利益-付费-发言权”原则

荷兰的水税体系是一个独特的、分散化的系统，由区域水务局管理。基于“利益-付费-发言权”原则（利益相关者付费并拥有发言权），三种主要税收支撑区域水务局：

1. **水系统税**：用于防洪和清洁地表水，向业主、家庭、耕地/自然土地所有者收取
2. **污水处理税**：基于向污水系统排放的污染量收取（家庭和小企业固定费用）
3. **污染税**：向直接排放到地表水体的企业收取

该体系的成功经验：2009年之前的污染税非常有效，通过激励企业投资自己的处理设施，急剧减少了排放；处理能力从1300万人口当量增加到2200万人口当量；氮去除率从1981年的53%提高到2014年的86%[37]。

### 7.3 国际经验：新加坡的水价机制

新加坡通过经济工具支持需求管理，包括递增阶梯水价、水保护税和罚款。2017-2018年水价上涨30%。人均日用水量从2003年的165升降至2008年的156升，目标为2030年降至140升[38]。

### 7.4 中国城市污水处理费调整实践

深圳和上海均于2022年上调了污水处理费，标志着向成本回收定价的转变。以上海奉贤区2024年调整为例：

- 居民第一阶梯（0-220立方米/年）：综合水价4.05元/立方米（含供水2.25元+污水处理费2.00元按90%=1.80元实际征收）
- 非居民：5.99元/立方米（统一）
- 重污染企业：额外加收0.80元/立方米

## 八、PPP模式创新：从“保底水量”到“按效付费”

### 8.1 传统BOT/PPP模式的问题

现有BOT/PPP模式下，合同通常设有“保底水量”和按量结算机制，这直接与按效付费改革冲突。分析指出：“在现有BOT/PPP特许经营模式下，合同按量结算并包含保底水量，社会资本没有动力关心水质”[39]。

### 8.2 新型PPP模式设计

基于国内改革和国际经验，建议设计新型PPP模式：

1. **取消保底水量**：改为基于实际污染物收集量的弹性支付
2. **引入绩效扣减机制**：对进水浓度不达标、处理效果差等情况进行扣减
3. **全生命周期绩效合同**：将运营维护、管网修复、改造升级纳入统一合同，按综合绩效付费
4. **风险合理分配**：政府承担政策风险，社会资本承担运营绩效风险

### 8.3 案例：上海竹园PPP项目

上海竹园友联第一污水处理厂是上海首个百万吨级处理厂，一级处理能力170万吨/日，服务2350万居民，覆盖107平方公里。服务费为0.22元/立方米，比政府预估成本（0.38元/立方米）低约40%。这一成本节约得益于政府通过固定投资和土地提供间接补贴，以及PPP结构将财务风险从公共部门转移至私营部门——服务费与绩效和财团投资挂钩[40]。

### 8.4 案例：华盛顿特区环境效益债券

美国华盛顿特区水务局（DC Water）发行了2500万美元的环境效益债券（EIB），用于资助绿色基础设施项目。债券的创新之处在于：

- 绩效风险共担：如果径流减少超过目标，投资者获得额外收益；如果低于目标，投资者向DC Water支付
- 三级结构：径流减少<18.6%时，投资者支付DC Water 330万美元；18.6%-41.3%时，债券按常规30年债券运作（3.43%票面利率）；>41.3%时，DC Water支付投资者330万美元
- 债券于2026年9月全额偿还，无需罚款

EIB实现了三个目标：转移绿色基础设施绩效风险、通过严格测量和公开报告提高透明度、增强未来决策能力[41]。

## 九、雨水-排涝-污水处理协同机制设计

### 9.1 协同机制框架

基于国内外经验，建议建立以下协同机制：

1. **统一调度平台**：将污水处理厂、泵站、排涝闸门、海绵设施纳入统一调度系统
2. **联合绩效评价**：将污水处理绩效与排涝达标率、河道水质改善等指标联动
3. **成本分摊机制**：明确雨水-污水共用设施（如合流制管网、泵站）的成本分摊比例
4. **应急联动**：暴雨期间，污水处理厂提前腾空库容，泵站与排涝闸门协同调度

### 9.2 案例：上海排水体制改革中的雨水协同设计

上海改革方案明确规定：
- 防汛责任（属地）不变，确保防汛工作不受影响
- 泵站排放需符合生态环境要求
- 低水位运行管网，减少外来水渗入
- 暴雨期间，污水处理厂无溢流（极端天气除外）
- 应急响应30分钟内

### 9.3 国际经验：哥本哈根的“六步法”

哥本哈根云雨管理计划的“六步法”为协同设计提供了系统路径：

1. **数据收集与调查**：确定威胁区域优先级
2. **建模与制图**：划分雨水流域
3. **成本效益分析**：量化不作为的成本（至2110年每年6000-9000万美元损失）
4. **设计**：使用“云雨工具包”中的多功能、灵活元素
5. **公众参与**：迭代优化
6. **详细社会经济成本效益分析**：比较不同方案

1. 启动成本监审，摸清全生命周期成本底数

## 十一、结论与展望

中国城市排水系统从核拨制向按效付费的转型，不仅是一项财政改革，更是一场深刻的体制机制变革。核心在于：

1. **打破厂网分离**：通过统一运营主体，实现全链条绩效问责
2. **重塑付费逻辑**：从“按量付费”转向“按效付费”，让资金跟着环境效益走
3. **覆盖全生命周期**：从建设到退役，系统化控制成本、提升效率
4. **整合雨水协同**：将排水系统与海绵城市、排洪排涝系统融合，实现“1+1>2”的协同效益

上海的“厂站网一体化”改革、武汉的“厂网一体”实践、长沙的“按效付费”模式，以及深圳的数字化运营，都为中国城市提供了可复制的经验。国际经验——新加坡的PUB统一管理、哥本哈根的蓝绿协同、费城的绿色基础设施、荷兰的绩效基准体系——进一步验证了改革方向的正确性。

改革不是一蹴而就的。需要分阶段、有步骤地推进，同时保持政策的灵活性和适应性。关键在于：建立强有力的领导协调机制，设计科学的绩效评价体系，完善配套的财政和价格政策，并积极引入社会资本和市场机制。

最终目标是通过制度创新和技术创新，实现排水系统的“降本增效、良性循环”，让每一分钱都花在刀刃上，让每一滴污水都得到有效处理，让城市水环境质量持续改善，让人民群众有更多的获得感、幸福感、安全感。
