# Generative-AI Voice Assistants in Production Passenger Vehicles (January 2023 – August 2026)

## Comprehensive Research Report

This report identifies all passenger vehicle automakers that publicly launched a generative-AI voice assistant in production vehicles (not a pilot or beta) between January 2023 and August 2026. Each entry includes the automaker name, assistant name, LLM partner, launch region, launch month/year, and links to the official press release and a reputable automotive-tech publication.

---

## 1. Mercedes-Benz

### MBUX Voice Assistant – AI-Driven Knowledge Feature (December 2024)

- **Automaker:** Mercedes-Benz
- **Assistant Name:** MBUX Voice Assistant ("Hey Mercedes")
- **LLM Partner:** Microsoft Azure OpenAI Service (ChatGPT) + Microsoft Bing Search
- **Launch Region:** Global (over 3 million vehicles)
- **Launch Month/Year:** December 2024
- **Details:** Mercedes-Benz rolled out a new AI-driven general knowledge function as a free over-the-air update. The assistant answers general knowledge questions (pop culture, geography, science, history) by performing a Microsoft Bing search and generating natural language responses via ChatGPT through Microsoft Azure OpenAI Service. The system is context-aware, enabling follow-up questions. Available initially in German, British English, and American English. Compatible with 1st, 2nd, and 3rd generation MBUX infotainment systems. [1][2][3]
- **OEM Press Release:** [Mercedes-Benz USA Media: Human-like Conversations with Your Mercedes-Benz](https://media.mbusa.com/releases/human-like-conversations-with-your-mercedes-benz-enabled-by-mbux-voice-assistant-and-ai-driven-knowledge-feature)
- **Publication:** [Motor Authority: Mercedes Voice Assistant Adds AI](https://www.motorauthority.com/news/1145323_mercedes-voice-assistant-adds-ai-to-enhance-functionality)

### MBUX Virtual Assistant – 4th Generation with Cerence AI (2025–2026 CLA)

- **Automaker:** Mercedes-Benz
- **Assistant Name:** MBUX Virtual Assistant (4th generation)
- **LLM Partner:** Cerence AI (core AI technologies) + ChatGPT4o + Microsoft Bing Search
- **Launch Region:** Global
- **Launch Month/Year:** 2025–2026 (debuts in all-electric Mercedes-Benz CLA)
- **Details:** Cerence Inc. announced that its core AI technologies power the new agentic voice assistant in the all-electric Mercedes-Benz CLA, marking the first deployment of the fourth-generation MBUX and MB.OS. The system features a "living" avatar of the Mercedes-Benz star and can adapt emotional speaking styles. Uses generative AI based on ChatGPT4o and Microsoft Bing Search to control vehicle functions and answer questions conversationally. [4][5]
- **OEM Press Release:** [Cerence AI Powers In-Car Experience in Premier German Automaker's New Electric Sedan](https://investors.cerence.com/news-events/press-releases/detail/92/cerence-ai-powers-in-car-experience-in-premier-german-automakers-new-electric-sedan)
